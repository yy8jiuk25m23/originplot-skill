# ICP 精氨酸峰位置异常候选与嵌套剔除敏感性分析

## 结论与推荐

**主推荐：D 组剔除 0 条，L 组剔除 0 条；每组保留全部 35 条。**

D 组有统计异常候选，但原始数据没有缺失点、边界峰、并列最高峰或不完整半高交点等已检测到的采集问题；这些检查不能排除尚未记录的仪器或样品问题。剔除曲线未出现明确持续稳定平台。因此，目前的证据不足以将候选判为错误数据。保留完整数据作为主要结果，并报告候选剔除的敏感性，是较稳妥且可追溯的选择。

## 原始数据与电压换算

两份真实 Excel 各含 X 和 Y1–Y35，150000 行有效数值，X=0–149999，步长 1。重新读取原始 Excel 的实际 XML 单元格，未依赖文件中不正确的工作表维度元信息。保留原件和 SHA256，不覆盖源文件。文件内除表头外主要是 UI 设置，未找到电压标定关系。

**所有 mV 数值暂按 V_AC=X×0.002 换算，未经仪器电压标定确认。**300 mV 来自用户提供的实验参数；150000 个采样间隔对应 0–300 mV 为本次暂定假设，最后一点对应 299.998 mV。校准关系若有变化，必须重新计算对应电压统计。

每条扫描独立 I/Imax 归一化。直接在原始未对齐信号中取全局最高峰，全部 70 条均为唯一最高峰；不平滑、不拟合、不做峰位对齐、不扣基线、不重构峰形。FWHM 取包围最高峰的最近左右半高交点，仅对交点位置线性插值以测量宽度，不插入实验信号。归一化前后峰位置及 FWHM 已逐条核对不变。与此前代表曲线平移展示任务分开，本任务没有使用其对齐坐标。

## 三种方法的比较

方法 A 使用原始 35 条的中位数作为固定参考，按 |V−Median| 从大到小排序；相同偏差按原扫描编号从小到大打破平局。方法 A 没有异常判定阈值，**只提供候选顺序，不能把前 10 条都称为异常值**。各组完整 35 条固定排序见 Excel，前 10 条为：

- D：Y27、Y17、Y33、Y14、Y6、Y18、Y34、Y20、Y15、Y10。
- L：Y2、Y14、Y30、Y11、Y4、Y31、Y16、Y19、Y6、Y28。

方法 B 为严格超出 Q1−1.5IQR 或 Q3+1.5IQR。分位数采用 NumPy 的 linear 插值定义；全程固定完整数据阈值。

- D：下界 127.668500，上界 136.824500 mV；候选 **Y17、Y27、Y33**。
- L：下界 138.349000，上界 151.541000 mV；**无候选**。

方法 C 为 0.6745(V−Median)/MAD，严格 |Z|>3.5；MAD 为未缩放中位数绝对偏差，两组均非零。

- D：候选 **Y17、Y27**；Y33 仅被 IQR 标记。
- L：**无候选**。

因此两种阈值方法在 D 的 Y17/Y27 上一致，在 Y33 上有差异；在 L 没有异常候选这一点一致。这是统计筛查的一致性，不能替代采集记录核查。

## 逐步剔除与平台判断

两组各计算 k=0–10 的 11 档方案，始终从同一固定排序前端依次删除。每档均记录 12 项要求指标及额外 MAD/IQR/FWHM SD、具体保留/删除编号、770 条逐扫描成员状态。k=0 相对上一步的变化量为空，表示不存在上一步；相对完整数据的偏移为 0。

D 前三步 SD 降低约 0.329、0.348、0.258 mV；第 3 步后单步降幅变小，可描述为斜率变化。但 k=3 后 SD 仍继续下降，均值也继续移动，不能将这一点认定为已确认稳定平台。L 各步 SD 缓慢下降，没有明确拐点，而且两种阈值法均未给出异常候选。没有预先验证的仪器容许漂移或稳定性界限可用于确立强制停止阈值。

每组剔除 3 条时保留率为 91.43%，剔除 4 条时降为 88.57%；90% 优先原则用于提醒数据损失，不能凭它认定某个方案正确。对中心数据进行截尾本就容易降低 SD，不能只凭降低 SD 决定剔除，也不能据此宣称仪器实际重复性提高。

## 候选剔除的敏感性对照

**D 删 3 / L 删 0**仅作为有阈值候选支持的敏感性情景，不作为已确认应删除的数据处理方案：

- 删除 D 的 Y27、Y17、Y33；D 保留 32 条（91.43%），L 保留 35 条。
- D 均值由 132.712286 变为 132.104562 mV，偏移 -0.607723 mV。
- D SD 由 2.560159 变为 1.624845 mV，下降 36.53%。
- ΔV 由 12.183486 变为 12.791209 mV，变化 +0.607723 mV。
- 上述 ΔV 变化是候选剔除带来的敏感性，不是选择该方案的优化目标。

另附 D 删 2（Y27/Y17）/L 删 0 情景，作为修正 Z 阈值候选的对照。若后续从采集日志、样品记录或预先制定的质量标准确认候选确实无效，可据此更新推荐；原始完整数据对照仍应保留。

## 全部 121 种组合

D、L 各 0–10 条嵌套剔除形成 121 种组合，没有遍历任意子集。ΔV 范围 11.784560–13.235387 mV；热图逐格保留 3 位小数，Excel/CSV 保留更高精度。未将最大 ΔV 标为最优方案。完整数据与主推荐均位于热图 (0,0)，用两个边框同时标示。

“分布是否重叠”在表中明确操作化为保留观测值的 **[最小值,最大值] 区间是否有交集**。本次 121 种组合的观测范围均不重叠；这不意味着总体分布完全不重叠，也不是显著性检验或置信区间比较。扫描编号是否对应真实时间顺序、扫描独立性和仪器漂移机理尚未确认，因此不推断时间趋势或报告依赖独立性假设的 p 值。
