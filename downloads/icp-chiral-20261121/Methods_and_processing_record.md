# ICP D/L-Arginine processing record

**实验**：Ion Cloud Profiling (ICP)；D-Arginine、L-Arginine；添加Verapamil Hydrochloride；两组频率相同。300 mV实验参数来自用户，文件没有提供频率数值。

**原始读取**：每组150000个有效X采样点，X=0…149999、步长1；每组y1…y35共35条曲线。原始文件各有一个工作表，其A1维度元信息不正确，因此流式读取实际XML单元格。

**非数值信息**：表头和AM/AN列UI设置被单独记录。D的Relative=True、L的Relative=False，二者强度尺度不同，因此不直接比较原始峰高。未发现扫描电压范围、单位换算或电压标定参数。

**电压换算—重要**：暂定V_AC(mV)=X×300/150000=X×0.002。此关系是用户指定的线性扫描范围假设，不是已验证的仪器电压标定。所有mV峰位、SD、FWHM和ΔV均随标定斜率变化。末点为299.998 mV，而非将149999强制映射为300 mV。

**归一化**：每条曲线分别除以其原始最大值，使最大值为1；不扣基线、不平滑、不拟合、不进行峰形重构。所有原始数值与归一化数组均保存。

**有效扫描**：70条扫描均有完整数值、非负信号和正最大值，均有效并全部纳入总体统计；未删去任何异常值。

**峰位**：每条曲线在全部150000个点中找全局最高峰，当前70条均有唯一最高值。后续若最大值重复则采用原始X最小者并记录重复计数，不静默筛选较有利峰位。

**FWHM**：不扣基线的Imax/2半高阈值，寻找包围全局最高峰的最近左右交点，仅用相邻实测点线性插值确定半高交点位置。该插值仅用于宽度测量，不插入绘图信号点。

**总体统计**：峰位均值、中位数、样本SD(ddof=1)由所有35条有效扫描计算；FWHM同时提供每扫描值、组均值、中位数、样本SD及代表曲线值。

**代表曲线筛选**：首先最小化峰位与该组中位数的绝对距离；只有距离完全相同时，优先左右半高交点完整、采集标记更少，再按原始扫描编号。D=y16、L=y20，均唯一命中中位数，未为增大差异而择优。

**整体平移**：V_aligned=V_original−V_peak+V_mean。D平移+0.754285714286 mV；L平移+0.319771428571 mV。仅坐标整体加常数，不改变任意强度值或采样间距。已逐项核对平移前后FWHM相同。

**离群标记**：D组y17、y27、y33仅被Tukey 1.5×IQR规则标记以便追溯，仍全部参加均值、SD和中位数统计；不把这些标记作为删除理由。

**主图含义**：主图是两组真实代表扫描归一化后、平移至各组平均峰位置的3D线瀑布图，既不是35条曲线的平均峰形，也不是未经处理的原始同时实测双峰谱图。

**视窗**：主图X显示120–160 mV，采用相同电压尺度；已核对该范围包含两条代表扫描的完整主峰和局部尾部。完整0–149999采样坐标的代表曲线另存CSV.GZ，完整35条原始/归一化矩阵存NPZ。

**三维属性**：使用真正3D折线：X=平移后电压、Y=分类样品深度(D=0、L=1.8)、Z=归一化强度。无散点、柱体、曲面或曲线下填充；D位于前方，X从左向右递增。

**字体及导出**：Arial Regular；轴标题13 pt，刻度11 pt，峰位标注11.5 pt，曲线1.9 pt。600 dpi TIFF/PNG为7680×4320，16:9；PDF保留矢量曲线和内嵌Arial字体。

**渲染软件**：已读取并采用Origin Skill数据与图形控制规范；当前Linux无本地Origin/OriginPro，用户要求直接解决，因此实际图形由Matplotlib mplot3d完成。附Origin可导入XYZ数据和FigureSpec；未生成或冒称Origin OPJU项目。
