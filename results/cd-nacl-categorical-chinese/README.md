# 六组试剂浓度组合的中文分类梯度散点图

本轮只输出一张中文单面板图：**六组试剂浓度组合_中文梯度散点图.png**。600 dpi，5433×3661 像素，标称230×155 mm。字体为思源黑体简体中文，数学上标缺字由DejaVu Sans补充。PNG由Python/Matplotlib生成。

## 横轴顺序与图形

六个等间距分类按用户指定顺序：CD50/NaCl1、CD100/NaCl1、CD100/NaCl5、CD100/NaCl10、CD200/NaCl1、CD200/NaCl5（均为μM）。刻度标签直接分两行显示完整CD和NaCl浓度，横轴标题为“试剂浓度组合”。每组显示全部原始空心采集点、实心均值与样本标准差误差棒。小幅横向错位避开均值中心，纵坐标强度保持原值。每组上方标注均值和CV。

一条细灰线按上述分类顺序连接全部六组均值，仅辅助阅读；相邻类别同时可能改变CD和NaCl，连线不是连续浓度响应、单变量因果曲线或对未测条件的插值。未测组合不绘制、不补零。

颜色按NaCl梯度协调：1 μM蓝色系、5 μM绿色系、10 μM红色。第四组CD100/NaCl10使用红色散点、均值、SD、分类标签及中文注释，突出均值降低和相对变异系数较高。

本轮重新读取全部六份最新上传的原始XLSX，文件名与SHA256在inputs.json中。不能使用更早的100/1三列文件或旧200/5文件替换。本轮文件均为五列采集，实际共30次；分析代码也支持按实际连续y列数量处理不足五列的文件，避免补齐。

## 核查与复现

重新计算的30个峰高与最新六文件上轮独立openpyxl源单元格和完整峰窗口核查一致。本轮再次核对输入哈希、每组采集数及均值/样本SD/CV。图程序检查30个散点Y值与峰高逐项一致、图中仅一个坐标面板、一条均值连接线、所有散点和SD均未超出坐标边界。已目视检查每组上方统计标注和原始点可见性。

quantification.xlsx、individual_peaks.csv、summary.csv、target_window.csv和audit.json为审计数据，不是额外图件。FigureSpec.yaml记录本轮分类图设计。原始文件不重复提交至结果目录。

安装requirements.txt内依赖；六份原始文件集中放置时用CD_NACL_INPUT_DIR指定目录，否则使用inputs.json中的当前上传路径。运行analyze.py，再运行plot_figure.py。用CD_NACL_FONT指定官方SourceHanSansSC-Regular.otf位置；font_source.json记录官方来源与字体哈希。
