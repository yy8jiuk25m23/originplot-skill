# 六组环糊精–NaCl 条件下目标离子峰强度及重复性的中文单图

本次仅输出一张单坐标系中文科研图：**六组浓度_目标离子中文对比图.png**。白底、思源黑体简体中文，600 dpi，5196×3661 像素（标称 220×155 mm）。图中完整显示六个已测浓度组合、全部30次采集、均值与样本标准差；没有额外面板或额外图件。

## 输入与方法

使用用户最后一轮上传的六份文件，以 inputs.json 记录的文件名与SHA256为准。三个100 μM环糊精条件使用最新的五列数据。不得使用更早的100/1三列文件或旧200/5文件代替。未参与本轮读取的文件不用于计算。

A列为 m/z，B–F 为 y1–y5。仅在含端点的 m/z 590.10–590.32 窗口逐列提取目标峰顶强度。30列在该窗口均有唯一内部局部最大值，未触及窗口边缘。无强度求和、相邻峰合并、平滑、基线校正、归一化、异常值剔除、缺失值填补或推断统计。样本标准差使用 n−1；变异系数=样本标准差/均值×100%。图中的除以10⁶仅为单位换算。

环糊精为100 μM时，NaCl从5增至10 μM，实测平均峰强度下降79.5427%，10 μM组变异系数为72.8162%。图中分别四舍五入标注79.5%和72.8%。这些是描述性结果，不代表通过统计显著性检验。采集列不被当作已确认独立的生物学重复，也不被赋予未经确认的时间语义。信号变化只能提示潜在盐相关抑制，不能单凭此证明离子抑制机理。最高均值不等于全局最优条件。

## 图形语义

颜色和符号共同区分环糊精浓度：50 μM为青色圆形、100 μM为蓝色方形、200 μM为紫色菱形。空心点为原始采集峰高；实心点与误差棒为均值±样本标准差。不同环糊精组在同一NaCl刻度附近固定错开，个体采集再轻微横向错开；纵坐标强度完全不变。仅连接同一环糊精条件的实测均值，作为视觉引导，不用于预测或插值。未测组合不出现、不补零。红色注释只强调100 μM环糊精、10 μM NaCl条件，不改变颜色所代表的环糊精身份。

## 核对与复现

分析直接读取XLSX中的XML，独立复核使用openpyxl读取原始文件的30个来源单元格与完整峰窗口，并使用statistics.mean/stdev重算六组统计，结果一致。quantification.xlsx、individual_peaks.csv、summary.csv、target_window.csv和audit.json保留可审计数据；这些不是额外图件。

安装requirements.txt内软件。原始文件在同一目录时，设置CD_NACL_INPUT_DIR到该目录；否则inputs.json记录当前工作区的上传路径。运行analyze.py，然后plot_figure.py。脚本严格核对输入哈希，拒绝同名但不同内容的旧文件。字体取自Adobe官方思源黑体仓库，下载到fonts/SourceHanSansSC-Regular.otf，或用CD_NACL_FONT指定位置；font_source.json记录下载地址和本次字体哈希。所有中文使用思源黑体，仅缺失的上标数学字符使用DejaVu Sans补充。字体本身未重复提交到结果目录仓库。
